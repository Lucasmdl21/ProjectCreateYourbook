# 📚 Criador de Livros - Deploy no GitHub Pages

## Resumo Rápido

### 1️⃣ Crie o repositório no GitHub
Acesse https://github.com/new e crie um repositório chamado `ProjectCreateYourbook`

### 2️⃣ Conecte seu projeto local
```bash
git remote add origin https://github.com/SEU_USUARIO/ProjectCreateYourbook.git
git branch -M main
git push -u origin main
```

### 3️⃣ Configure GitHub Pages
1. Vá a **Settings** → **Pages**
2. Selecione **Deploy from a branch**
3. Escolha **gh-pages** como branch
4. Clique **Save**

### 4️⃣ Deploy
```bash
npm run deploy
```

### 5️⃣ Acesse
```
https://SEU_USUARIO.github.io/ProjectCreateYourbook/
```
